# 安全模型

Plums 当前为预览软件，只应安装来自信任来源的扩展。权限声明、用户同意、执行授权、范围和审计共同决定是否执行；导入组件本身不授予权限。

## 档位上限与组件授权

每个 Agent 的档位上限为沙箱 < 项目 < 整机，默认沙箱。上限只限制、不授予权限。组件必须声明自己的本地执行入口和档位，并经可信管理窗口确认当前组装与范围；未声明并确认本地执行的组件不能启动本地入口。

执行项绑定组件安装身份、入口声明、档位、目录与主机范围。扩大范围、增加本地执行组件或提高上限须重新确认；正常升级可沿用匹配的授权。导出不携带授权，导入后的上限为沙箱。调用链不能使调用方取得执行组件的本地授权。

| 档位 | 当前行为                            | 边界                                                        |
| ---- | ----------------------------------- | ----------------------------------------------------------- |
| 沙箱 | 默认，无本地进程执行                | 普通扩展通过隔离运行时与宿主能力接口工作                    |
| 项目 | 当前不可用，返回 `TIER_UNAVAILABLE` | 容器、启动和注入尚未完成；不得回退整机或无沙箱执行          |
| 整机 | 声明并确认后可执行本地入口          | 没有 Plums 沙箱，拥有操作系统账户可用的文件、网络及程序权限 |

普通业务 JavaScript 使用各组件独立的 Node 子进程和 V8 isolate，默认 64 MiB 内存及五秒同步执行预算，等待宿主不计入预算。第三方前端在独立沙箱视图中运行，隔离上下文、关闭 Node 集成，并阻断直接联网和任意导航。整机本地入口不使用 isolate 的五秒预算。

## 确认与撤销

能力调用按校验、安装与声明、同意、范围、确认、复核、放行审计、复核、Sink、结果审计处理。确认或审计等待期间授权、路径或安装身份变化须阻止执行。只有布尔 true 才放行单次确认；缺失、异常、无效结果和超时均拒绝。

DesktopHost 使用 `task-or-confirm`：未被有效任务范围覆盖的 read/list 也需单次确认。任务绑定当前组件实例、版本、声明、目录与调用链，有期限且可撤销。组装汇总确认可以覆盖位于已确认项目目录内的组件 fs 和受控命令范围；这不使项目本地运行时可用，也不覆盖 HTTPS 外发、资源或 MCP 批准。

策略默认不启用。用户明确选择策略最大范围与期限后，allow 才能在该范围内替代单次确认；deny 优先，策略不能扩大声明、同意或授权。策略失效、超时或结果无效时，本需确认的操作回退可信确认窗口，无确认环节的操作拒绝。

降低上限、撤权、停用、更新及绑定变化先停止受影响的入口与依赖任务，保留无关入口。关闭前端可以保留本地进程，完整关停须等待 `DesktopHost.close()`。整机当前仅采用进程组监管：停止或撤销该入口后，它启动且已脱离其进程组的子进程可能继续运行。

## 密钥与审计

密钥值只存 SecretStore；设置、清单和数据库保存引用。宿主按已声明并授权的目标注入凭据，普通扩展和包前端不能读取明文。Agent 配置与密钥分别存储，导出默认不含设置值、密钥、运行数据和执行授权。

能力和确认审计按 callId 关联，不记录业务正文、请求体、参数、输出或物理路径。整机本地执行审计只记录宿主可见的授权变更、进程生命周期、本地请求和代理连接；不记录本地程序直接执行的文件、网络及子进程操作。

Agent 接口与存储隔离不能限制整机程序的操作系统权限。整机扩展可访问账户能够读取的 Plums 数据及其他 Agent 的密钥，须在首次汇总确认中审阅该边界。

## 已知限制

- 项目档位的全后代容器、启动、安全配置落盘及凭据/代理注入尚未完整接入，继续失败关闭。
- 创建阶段硬链接检查及启动前校验不是内核级 inode 防线；非后代进程在运行期新增别名仍是未防护风险。
- 桌面安装包采用 ad-hoc 签名，未公证，没有自动更新。Gatekeeper 提示随系统版本变化；下载后操作不在源码验证证据范围内。
- 当前桌面目标为 macOS 27.0.1 arm64；macOS 15 arm64 CI 不能替代目标系统验证。
