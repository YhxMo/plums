# 合成状态恢复确认界面

可选 ESM 样板 `sample.restore-panel` 通过公开 `sample.restore@1` 服务取得预览和恢复能力，使用 ctx.view，不读 Host 私有状态。默认应用不加载样板；本阶段只对隔离合成数据运行，不授权恢复真实数据。

服务契约：`preview(signal?)` 返回 null（当前无适用快照）或 `{revision,from,to,current,target}`；`restore(revision,signal?)` 返回已确认 StoredState。提供者负责业务 schema、目标版本及 restorePreviousState 调用，UI 不解析业务格式。提供者必须只给出适用且经校验的目标，不能用目标版本代替业务验证。unknown错误通过 outcome 保留。

界面先读取预览，不写入。显示当前版本/修订号、目标版本和两侧JSON；打开确认对话框再次展示本次修订号与目标，取消/Escape回到发起按钮，不调用恢复。只有明确确认才传预览revision；后台变更由助手拒绝过期确认。提交期间禁用重复操作；成功仅根据恢复回执展示。普通失败保留当前状态并要求重新读取；unknown显示结果待确认，不声称未改数据、不自动重试，重新读取前禁用恢复。

关闭视图会取消操作信号并清理监听；回执晚到不能写回已卸载DOM。成功写入后的取消不代表回滚。读取失败独立显示且可重读，读取成功但没有适用快照不显示假成功。

退出条件：预览/取消/Escape零写入，明确确认一次写入；成功状态与实际文件一致，过期确认拒绝并可重读，提交失败和unknown有准确展示/锁定，卸载清理防止迟到DOM更新。浏览器桌面/窄屏与两端隔离原生分别留证；故障注入范围单独标明。不是通用包恢复UI、自动回滚或真实数据操作许可。
