环境 macOS、Node 24.19.0、pnpm 10.33.3；冻结锁文件安装、构建、全量测试和版本命令退出码均为 0。Windows 未实际验证；两项 FIFO 测试在 Windows 跳过。better-sqlite3 构建脚本告警仍在，本机通过不能替代各平台全新安装验证。

数据库 schema 2 自动升为 3，保存引用而不保存密钥值。旧内核拒绝升级后的数据库，迁移不会找回升级前已丢失记录的孤儿引用。清理失败时新版本可能已经安装，错误说明当前版本；相同 ZIP 仍受严格版本规则约束，重试清理应通过后续版本更新或卸载。
