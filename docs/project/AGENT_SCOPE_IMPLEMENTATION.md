# Agent 任务范围与扩展管理

实现说明核对于 2026-10-06。公开接口与完整执行契约见 [能力说明](../capabilities.md) 和 [桌面说明](../desktop.md)。

## 当前行为

- 服务接入和普通扩展统一展示，`connector` 清单、依赖、组合字段及凭据注入资格保持兼容。角色卡不签发能力。
- 独立 core 保持兼容确认策略；DesktopHost 每次创建或重建 core 使用 `task-or-confirm`。未覆盖的 read/list 也需要单次确认，撤销、到期或重建不会恢复隐式只读放行。
- 有限任务范围只由可信管理界面签发，SDK 不暴露签发接口。用户选择 fs 操作、HTTPS 目标和有效期；单次确认不写入任务范围，exec 不加入任务范围。
- 授权绑定当前 core/Agent、组件安装身份、版本、声明、目录和调用链，各方权限取交集。write 不隐含 read，范围不能扩大 manifest 声明。
- 请求在等待前复制；确认、异步审计及执行前重新复核。停止、撤权、到期、升级、配置或目录变化使旧授权失效，迟到同意不能放行旧调用。
- 授权和撤销以 taskId 关联执行审计，不记录业务内容、物理路径或密钥；批准审计失败不发布授权。
- 开始使用取消时保留配置界面；停用、撤权和运行恢复由可信宿主管理，包前端不取得管理接口。

## 验收边界

桌面没有登记真实 ExecSink，也没有本地 stdio MCP 或 OS 沙箱承诺。普通业务 JS 与经用户独立批准的本机引擎有不同边界，见 [SDK v2](../sdk-v2.md) 和 [引擎说明](../engine.md)。
