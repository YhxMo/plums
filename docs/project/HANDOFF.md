## 保留的边界与未完成内容

- 原生窗口实际鼠标拖动仍缺少通过证据；此前 Plums 和标准系统标题栏对照均未产生位移，不能据此认定实现故障。
- 未验证真实模型凭据对话、生图/TTS 协议、开发者签名/公证、自动更新、其他机器或跨平台长期稳定性。模型本地存储不依赖钥匙串，不将文件读写 smoke 当成系统密钥验收。
- 桌面未登记真实 ExecSink 和本地 stdio MCP；本机引擎拥有普通本机权限，不等于 OS 沙箱。
- 服务迁移工作树仍有未接入的 Gmail/macOS 服务和 schema 6 草稿；保留，未作为完成能力合入。旧产品方向与文档工作树的独有内容也保留，不能覆盖当前桌面实现。
- 个人助理位于独立 `plums-assistant` 仓库，依赖固定的未发布内核快照。应用、依赖、运行数据和未提交源码均保持原样，不自动替换为主线同版本包。
