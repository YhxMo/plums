# 实验导航选择契约

状态：当前有效（2026-10-17 核实）；实验导航契约，仅同进程路由与停用恢复。

可选纯函数 `resolveNavigation(entries, preferredRoute?)` 只选择贡献，不管理 DOM、生命周期、URL 或历史。每项为 `{id,route,label,priority,viewId}`，id 和 viewId 非空且分别唯一，route 为非空字符串，label 非空，priority 为有限安全整数。输入复制后选择，不修改调用者数组。

同一路径优先级数值较高者胜出；相同优先级按 ID 的代码单元顺序升序决胜，避免激活先后或 locale 导致变化。返回每条路径的胜出项、冲突诊断（胜出 ID 与落选 ID），以及 preferredRoute 的胜出项；该路径不存在则选路径排序第一项，无贡献则 selected 为空。不会自动覆盖注册或持久保存选择。

贡献者用公开服务登记元数据，同时用 ctx.view 注册对应 viewId，释放登记必须绑定 ctx.onDispose。管理装配仅对 Host.views 当前可用视图进行解析；停用当前贡献后关闭旧挂载，再挂载有效胜者。旧视图释放失败不能继续挂载新视图或声称恢复，管理入口独立保留并要求重启。视图挂载失败回退属于装配策略，不由纯函数提供。

本阶段限定一个非聊天工作台、两个同路由贡献及一个辅助路由。切换后将焦点移到内容标题；无贡献时焦点回到管理入口；清理失败留在独立管理区。只测试同进程路由与停用，不含浏览器 history、快捷键/主题冲突、持久化导航和完整 A12。

元数据可引用其他可信扩展的可用视图，属于组合策略，不是所有权证明。注册释放绑定登记者生命周期，但纯选择器和该样板不验证 viewId 的作者身份；共享可信环境不提供隔离或防伪装保证。
