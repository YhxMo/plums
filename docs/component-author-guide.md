# 组件作者：从声明到本地验收

在独立项目维护角色卡、业务扩展或连接器。Plums 仓库交付应用、宿主、SDK 和官方底座；内部自造夹具只用于回归，不是官方业务组件或可发布模板。

## 选择入口

| 要编写的组件   | 先读                                                                                     | 验证重点                                                |
| -------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| 角色卡         | [包格式与内核](core-guide.md)                                                            | payload 不透明；业务格式由解释它的扩展负责              |
| 扩展与工作界面 | [桌面声明与 SDK](desktop.md#桌面声明和-sdk-v1)、[SDK v2](sdk-v2.md)                      | 入口、贡献、沙箱界面、生命周期与错误状态                |
| 服务连接器     | [通用连接](sdk-v2.md#通用连接)、[扩展协议](extension-protocols.md)                       | 固定目标与凭据注入；协议解析在连接器内完成              |
| 本地执行入口   | [引擎与档位](engine.md)                                                                  | 本地执行声明、可信汇总确认与 Agent 上限；项目档位不可用 |
| 独立底座       | [底座作者指南](foundation-author-guide.md)、[符合性工具](common-contract-conformance.md) | 固定制品、SDK 桥、隔离、停止与独立符合性                |

包格式 2.x 的 `permissions` 是权限来源；SDK 和协议声明不授予权限。不要把 `prepared` 或 `evidence:"declared"` 当作真实服务或调用成功。

## 在临时 Agent 完成本地路径

1. 按公开包格式制作 ZIP。根目录放 `manifest.json`，列出包内入口；只打包需要的文件，不带依赖缓存、真实密钥或运行数据。
2. 在 Plums 导入自己的 ZIP，选择继续组装，创建自造测试 Agent。导入公共库只保存制品；审阅来源、配置和声明后，再通过可信窗口启用。
3. 在详情页处理使用前检查中的字段、协议连接和权限条件。以宿主返回的字段、需求槽和入口标识定位问题，不在前端推断授权。
4. 在设置页开启开发者模式，通过详情页的开发者调用测试贡献。先测离线返回，再逐项测拒绝、取消、停用、重启和更新；涉及真实服务时只使用专门的测试账号，并批准精确目标。
5. 在执行记录查看 `callId`、阶段和执行状态。`unknown` 或 `completed` 先核实实际结果，不自动重试。反馈问题时附制品版本、声明 id 与调用阶段，排除密钥、正文和原始输出。

CLI 的 `inspect` 可检查 ZIP 的内核包格式，但不会验证全部桌面声明，也不会执行组件。CLI 使用内存密钥和 Recording 外发；它不能替代真实桌面连接器验收。命令及临时 `--home` 用法见 [core 与 CLI 指南](core-guide.md)。

## 发布新版本前

在开发者内容页可创建私有工作副本，校验并保存更高版本；外部编辑完成后重新读取。公共库的新版本不会自动替换其他 Agent 已固定的制品。只有显式更新的 Agent 应用新版本；权限或范围变化继续确认。

分别核对文本回复、多轮历史和工具结果回传等实际实现的路径。普通聊天不强制函数工具，不宣称未验证的协议、生图或语音支持。停止与撤权不回滚已经发生的副作用；整机入口还可能遗留脱离进程组的后代。

分享 Agent ZIP 会排除设置值、密钥、授权和运行数据。需要完整恢复时，用设置页中的停机备份指引，并阅读 [兼容与恢复](desktop-recovery.md)。签名、公证、真实服务和真实外部作者符合性必须有各自证据，内部夹具通过不能代替它们。
