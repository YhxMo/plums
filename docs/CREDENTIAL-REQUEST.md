# 凭据代用请求契约

状态：当前有效（2026-10-18 核实）；实验类型、测试参考适配器与 [DeepSeek 协议扩展](DEEPSEEK.md)已有本地实现；[通用绑定与原生凭据管理](CREDENTIAL-BINDINGS.md)已接入 Mac/Android 代码及宿主管理入口。生产 `PlatformAdapter` 仍不提供 `credential.request`；受限传输、系统秘密用于传输的读取/注入和发送授权按[当前阶段 R4 最小安全集](spec/milestone.md#r4-最小安全集)实施，尚未接通；本文中 DNS 固定、吊销联网边界、显式代理传输与授权世代等要求移入[后续加固](spec/total.md#后续加固)，R4 实施时同步精简本文。系统秘密实际操作与真实外发分别验收；接口正式稳定前仍须 iOS 最小验证。

本契约是凭据请求、授权、失败边界和证据要求的唯一详细来源；路线、当前任务与工作包分别见[整体计划](spec/total.md)、[当前阶段](spec/milestone.md)和[M2 退出清单](spec/M2-EXIT-CHECKLIST.md)。

连接器提交序列化载荷并取得响应，只引用自己的非秘密绑定名。平台管理凭据、精确目标和请求政策；扩展构造 JSON 等载荷并解析业务响应。

## 作者接口

扩展 manifest 声明 `capabilities: ['credential.request']`。激活后调用 `ctx.platform('credential.request', { version: 1, binding: 'text', body: 'hello' }, signal?)`。类型 `CredentialRequest`、`CredentialResponse`、`CredentialFailureOutcome` 由 SDK 导出；`platform` 仍返回 unknown，作者按契约校验响应。

请求只接受 version/binding/body；body UTF-8 不超过 4096 字节。不得传 owner、URL、头、方法或原始凭据。调用者身份由 Host 转为 `extension.<id>`，绑定在这个平台 owner 内解析；同名绑定不代表跨扩展授权。绑定配置与普通业务配置分开，别名不是秘密或授权证明。

成功响应为 `{ status, body }`，状态 200–599 且排除 3xx，正文 UTF-8 不超过 8192 字节；HTTP 4xx/5xx 保留给扩展解释，不自动重试。适配器不返回头或凭据；这不保证远端正文绝不回显秘密，真实目标仍须可信。

## 生产接入

首个交付单元为：一个真实模型连接器通过公开 `text.transform@1` 接入现有 Agent，完成一次非流式、非思考、单次输入输出。模型协议、载荷构造、结果解析和模型选择归连接器；SDK/原生平台承担绑定、秘密、发送授权、受限传输和清理。模型名在真实操作前按官方文档和账户可用模型核对；`deepseek-flash` 只是当前代码默认值，未核验前不当作已确认服务合同。

| 项目 | 首个参考接口与实现归属 |
| --- | --- |
| 目标与方法 | 精确 `https://api.deepseek.com/chat/completions`，POST；由平台绑定批准，不能由扩展在请求中改写 |
| 媒体类型与固定头 | `application/json`；不沿用其他服务的协议版本头，额外头按实际接口需求批准 |
| 认证 | `Authorization: Bearer …`，原生从绑定的秘密引用注入；扩展只能引用自己的 text 别名 |
| 载荷 | 扩展序列化 model、max_tokens、单条 user message、`stream: false` 和 `thinking: { type: "disabled" }`；只发当前文本，不发历史或角色说明。输出预算默认 256，属扩展配置 |
| 响应 | 扩展读取 choices[0].message.content 并检查 finish_reason；只接受完成文本，截断、工具调用、过滤或坏 JSON 都不当完整回复，不向 UI 交付 reasoning_content 或原始 JSON |

`extensions/connectors/deepseek.js` 已实现上述协议，经隔离假平台验证与现有 Agent 消费者的公开服务接线、错误、取消及切回本地。普通包仍不提供真实能力，扩展不加入默认目录、不自动启用；启用/恢复已存结果不自动发请求。生产适配须同步 `AgentStore.info`、默认角色说明、能力字段和关于文案，覆盖 Agent 与共享工作台的实际来源与文本外发范围。多轮历史、流式、工具调用、OAuth、MCP 和多 Agent 协作另分阶段。

Android 正式 verifier 不接受应用 `NetworkSecurityConfig` 的私有根，reqwest 的额外根合并在该平台也不支持。受控证书夹具只能使用独立测试 companion 的内存 mock 信任库，不能进入普通包；测试模式跳过的吊销路径不作为生产证据。根随 OS 更新；Android 已初始化的信任管理器/根缓存还须核对进程重启后的重载，不承诺实时轮换。

**后续加固（不阻塞 R4）：OS 证书验证的辅助联网。** 上游两端验证器存在 OCSP/CRL 或根获取路径，它们不自动受 reqwest 的 DNS 固定、`no_proxy`、代理或超时配置约束。平台维护者须用受控反例查明可强制的边界，再决定约束实现或经独立审查修订支持声明；无法满足时重新评估验证/传输方案，不静默放宽目标、代理、时限或关闭 TLS。此实验没有验证生产辅助联网与吊销行为。

真实调用前由资源所有者确认：扩展 ID/来源/版本、精确目标、媒体类型/固定头/认证、合成文本、测试账户/凭据、每端请求次数与 max_tokens 上限、人工费用/余额核对和撤销负责人。官方 API 若无每请求预算接口，应用不承诺自动精确费用封顶；密钥只在原生面板录入，不通过聊天、仓库或命令输出提供。

## 绑定、授权和秘密分开管理

- **绑定记录**由宿主管理入口创建，键为 `(extension owner, binding alias)`，内容为来源/版本、用户可读目标名、规范化精确 HTTPS URL、内容类型、固定非秘密请求头、认证注入策略、秘密引用和绑定修订。扩展只能引用 alias，不能创建绑定、指定 owner、替换政策或读取秘密。非秘密记录不进入普通扩展配置，组合只保存绑定需求，不携带授权或秘密。
- **发送授权**按本次应用进程及 owner 世代保存。管理者展示扩展来源、目标、POST、内容类型、固定头、认证头名称、文本外发、路由和限额，明确确认后才启用，不展示秘密值；绑定存在不等于授权。目标、头/认证政策、秘密、来源或路由变化使原授权世代失效，重新确认；同 ID 重装也不继承旧授权。授权只约束本应用的公开 `ctx.platform` 路径；共享 WebView 中的同环境代码仍可能直接触达原生桥接，不能把应用内提示称为恶意扩展隔离。
- **秘密输入**走宿主原生输入面板，直接进入秘密存储，不经过扩展表单、JS 状态、日志或 source.patch。首次实现只接专用低权限测试令牌。Mac 使用 Keychain Services 的应用专属项目；Android 使用 Android Keystore 管理的密钥加密令牌密文，密文留在应用私有且排除备份的文件中。Keystore 存密钥，不把任意令牌误称为直接存入硬件；硬件支持单独探测，不作为所有设备保证。
- **创建回执**须在秘密写入和绑定元数据提交均确认后才显示成功。部分创建保留可诊断 pending 记录并拒绝请求；秘密写入回执未知时先核对，不重新生成或静默覆盖。删除孤立秘密是管理恢复动作，不交给扩展。
- **撤销**先在请求入口使世代失效并阻止分发，通知在途请求取消，再持久化禁用记录并删除秘密。删除或持久化回执未知时保留禁用/待核对状态，不报已删除；下次启动未核对的绑定不可用。停用释放在途资源但保留绑定，卸载保留显式禁用记录，秘密去留由管理者明确选择；重装不自动复活。进程退出后授权为空，持久绑定不能自动发请求。
- **实际秘密操作**（Keychain/Keystore 保存、读取、删除、拒绝/锁定/失效、签名变化）与真实外发分别确认范围、分别留证；本地代码和模拟失败路径不等待这些权限。Mac 调试临时签名包更换签名后的 Keychain 访问、Android 密钥失效及备份还原必须分平台实测。

## 精确目标与传输政策

绑定只允许一个规范化 HTTPS URL（固定 scheme、host、443 端口、path；首版不接受 userinfo、query、fragment）。绑定创建和每次分发都校验；请求不得拼接路径或添加查询。明确拒绝所有 3xx，不跟随；拒绝证书/主机名错误，不提供“忽略 TLS”或降级 HTTP。TLS/JNI 机制已限定验证（见上节）；公网系统根正例、实际秘密和完整受限网络矩阵仍须独立验收。

两端默认公网 HTTPS 直连，禁用环境/系统自动代理；管理者可明确配置无账号密码的 HTTP(S) 代理，保存为独立 route 政策，目标仍为原官方 API，扩展不能按请求自行选代理。代理配置修改递增绑定修订，后续发送授权须覆盖所选路由；目标证书验证保持。代理传输的 CONNECT/DNS 及失败行为须单独验证，保存配置不代表代理传输已通过。API 中转/网关后续作为独立接入方式支持；不更改全局网络或系统信任设置。直连基线下，目标主机解析结果必须为允许的公网地址，拒绝回环、私有、链路本地和保留地址，包括 IPv6/IPv4 映射形式。校验的地址须约束实际连接，TLS 仍校验原主机名，不能先检查 DNS 再让 HTTP 栈重新解析；自定义 resolver/连接策略必须用 DNS 改写反例验证。生产能力不复用实验的 localhost 豁免。

每个绑定明确保存 `Content-Type` 和固定非秘密请求头，首个真实接口使用 JSON 和 Bearer，其他服务所需的固定头/认证方式由各自绑定批准。认证注入支持 Bearer 或指定头名的原值注入；秘密引用只在原生侧解析，扩展不提交或读取认证头值，认证策略中不保存秘密模板。头名/值验证合法性、大小写归一及重复冲突，固定值和秘密注入值都拒绝 CR/LF；Host、Content-Length、Transfer-Encoding、Connection 及其他逐跳/代理头由传输层管理，不可由绑定覆盖，认证头也适用这些限制且不得占用 Content-Type。Content-Type 和认证头分别只由各自策略产生，固定头不能再定义同名项。不使用 cookie jar，不开放请求级任意头或扩展自行设置代理。

请求 UTF-8 ≤4096 字节；响应按实际读取累计 ≤8192 字节，校验 Content-Length 与分块，拒绝非法 UTF-8；不隐式解压，超限立即停止读取。HTTP 4xx/5xx 交给连接器解释，不自动重试；模型错误解析留在扩展。建议首版总时限 30 秒、连接时限 10 秒（含在总时限内），覆盖 DNS、TLS、发送、响应头和正文读取；最多每 owner 1 个、全局 4 个请求，满额在分发前拒绝，不增设持久排队。具体值属于待实施的资源政策，不是 800ms 回环实验的生产保证。原生请求所有权、取消通道和回收必须覆盖停用、撤权与窗口退出。reqwest 用 [redirect policy](https://docs.rs/reqwest/0.13.5/reqwest/redirect/index.html) 禁用跟随；配置正确仍需受控服务命中计数证明未访问跳转目标。

## 失败边界

失败边界按层区分，不能只引用一个 outcome：

| 层 | 拒绝/失败时的结果 | 可证明的事实 |
| --- | --- | --- |
| Host 进入平台适配器前（声明、能力、生命周期、公开 payload 结构） | `not-committed`（既有兼容语义） | 未进入平台适配器；没有网络分发 |
| 原生分发边界前（授权、绑定/世代、容量、请求体超限、政策、秘密读取，或可证明尚未开始网络 I/O 的拒绝） | `not-dispatched` | 原生可证明未开始发送网络请求；不缩小到远端未收到 |
| 原生开始 DNS/连接/TLS/发送后（取消、撤权、断网、TLS/代理/连接失败、3xx、响应超限/坏格式、超时、回执丢失） | `unknown` | 远端副作用可能发生；不自动重试；不承诺立即终止或撤销 |
| 完整响应交付前 | 重新检查授权世代 | 旧世代不交付；撤销后的迟到响应丢弃 |
| 已收到并验证通过的完整响应 | `{ status, body }` | HTTP 4xx/5xx 保留给扩展解释；响应超限或非法 UTF-8 不是完整响应 |

桥接永不返回需要前端等待截止和原生独立总时限，不能只用 Promise.race 隐藏仍运行的请求。取消成功只表示本地不再交付和继续等待，不表示服务端撤销。未知回执不自动重试；管理者先查看原请求状态，没有服务端幂等承诺时人工重试也提示可能重复副作用。

诊断只保存本地请求 ID、非秘密 owner/alias、绑定修订、阶段、耗时、字节计数、HTTP 状态或分类错误；禁止正文、原始异常、Authorization、秘密、完整目标 URL/查询及响应头。不默认持久化内容预览；环形记录首版最多 100 条，仅当前进程可查看。上游可能回显秘密：首版对完整响应中当前原始令牌的精确匹配拒绝交付，日志同样不记录；不能识别所有编码或派生泄漏，目标仍须可信，测试令牌保持低权限且可撤销。

## 隔离参考模型与失败验收

`tests/fixtures/credential-platform.ts` 的 FakeCredentialPlatform 仅测试引用：绑定目标限制为 HTTPS `.invalid`，凭据为固定 `fake-only` 字符串，无 fetch、持久化或原生桥接；它是可执行参考模型，不是扩展 API、原生实现或安全沙箱。现有 Host/回环实验可复用生命周期、`ctx.task`/`ctx.platform`、取消和未知回执语义，但不能证明生产网络、秘密或身份授权。

| 场景 | 必须拒绝或保留的事实 |
| --- | --- |
| 同名 alias 跨 owner、伪造字段、未声明/未授权/已停用 | 公开分发前拒绝；服务端零命中；其他 owner 的绑定/授权不变 |
| 非法/重复头、覆盖传输/认证头、修改媒体类型/固定头/认证策略 | 拒绝不合法绑定；有效政策修改使旧授权失效；日志无原始秘密 |
| 取消/撤权与分发竞争、撤权后再授权 | 旧世代不交付；不自动重试；已发送失败为 unknown |
| 秘密库锁定/拒绝/失效/签名变化、部分创建/删除回执丢失 | 不假报成功；禁用记录可核对；不降级明文 |
| 目标端口/路径变化、DNS 重绑定、私网解析、TLS 证书错误、代理失败 | 不访问未授权目标；保持系统安全设置；错误脱敏 |
| 3xx 跳转第二服务、非法 UTF-8、错误 Content-Length、分块超限、慢正文 | 第二服务零命中；限额/总时限生效；派发后 unknown |
| 服务端已成功但回执丢失、桥接永不返回 | 本地 unknown；无隐式重试；原生资源最终释放 |
| HTTP 4xx/5xx、响应回显令牌、原始异常含敏感字段 | 正常 HTTP 语义保留；原令牌不交付；日志不含敏感值 |
| 容量满、冷启动、Android 密文恢复但密钥缺失 | 分发前拒绝；进程授权不恢复；坏绑定保留并要求重新绑定 |
