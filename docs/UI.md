# 默认界面与跨端体验

[架构](ARCHITECTURE.md) · [扩展契约](EXTENSION-CONTRACTS.md) · [验证证据](../evidence/RESULTS.md)

状态：当前有效（2026-10-19 核实）；0.0.4 默认界面说明，验证范围见证据索引。

## 从添加 Agent 开始

0.0.4 默认显示 Agent 界面。零角色时显示品牌和“导入角色卡／安装扩展”两张引导卡，底部保留“从头添加 Agent”次要入口。已有角色但未选中时，桌面左侧保留列表，右侧只显示居中的低干扰 Plums 图标；角色是否接入模型不影响计数。选中角色后显示会话。手机无角色时显示上下排列的引导卡，已有角色时先显示列表，选中后进入会话。两端均可从“添加”进入添加方式菜单，创建角色、导入角色卡或查看扩展。模型连接器与 MCP 属于扩展能力，在扩展管理中接入。

内置提供者 `agents.local` 管理角色与会话，回复来自每个 Agent 在详情「模型」区选择的 `chat@1` 模型（内置[模型连接](MODELS.md)提供，可选依赖），可再开启 `text.transform` 扩展做后处理。开发构建另有回显模型与大写服务；没有模型时 Agent 界面照常打开，详情给出「添加模型连接」，打开模型连接对话框。添加表单显示实际提供者说明；导入角色卡不会改变执行能力或授予访问权限。实验 JSON 卡片需要 `name`，可选 `description`、`multiSession` 和 `version: 1`。支持选择本地文件、粘贴 JSON 或读取应用同源链接；外部链接需先下载文件，原生 CSP 保持原边界。此格式由扩展层解析，不是完整角色卡标准或 A2A 协议。

同源角色卡链接读取拒绝重定向，最多读取 32000 个 UTF-8 字节，10 秒内未完成则报超时；关闭或取消会中止读取，失败保留原输入。文件入口也限制 32000 字节。

## 列表、交互与详情

桌面布局为256px Agent列表、可伸缩会话区、可折叠的268px详情栏。默认右侧详情四角14px圆角，上、右、下各留10px；外侧占宽278px。列表提供搜索和添加；特别关注的 Agent 以头像快捷区和星标显示，仍可从全部列表进入。操作菜单支持鼠标、右键、触屏长按及键盘，包含特别关注、重命名、移除。删除前确认本地会话的删除范围。

点击角色进入会话。桌面会话采用即时通讯布局：头部显示角色头像、名称、状态和会话标题；消息带双方头像，对方气泡在左、自己的在右；相邻消息间隔超过 5 分钟时插入居中时间（今天 `HH:MM`、昨天、`M月D日`、跨年带年份），列表行在名称右侧显示末条消息时间。悬停或键盘聚焦消息显示复制、重新发送（仅自己的消息）、删除；右键打开同样的消息菜单，方向键切换、Esc 关闭并把焦点还给该消息。处理中禁用重新发送和删除，复制始终可用。底部输入区为浮起的圆角卡片：文字在上，右下角为圆形发送按钮，处理中换为同尺寸的圆形停止按钮；聚焦只让卡片边缘变亮，不显示橙色线，也不显示快捷键提示。写入派发后进入不可撤回的提交段，显示等待保存并禁用停止；成功回执优先。成功保存后清除对应草稿；失败和提交前取消保留草稿与上次保存的消息。输入与服务回复都在保存前验证字符串类型及 1,000,000 个 UTF-16 代码单元上限；会话消息分页存储，可达数 MB。桌面 Enter 发送、Shift+Enter 换行，输入法组词期间不发送；手机通过发送按钮提交。

详情栏展示人类可读的角色说明、实际能力、来源与版本、状态和特别关注。支持多会话的角色在这里新建、切换和删除会话；处理期间先停止任务再管理会话。删除最后一个会话后保留一个新的空会话。每个 Agent/会话拥有独立草稿。

单选使用与菜单同风格的下拉框（[`Select`](../src/components/Select.tsx)），不用原生 `<select>`：按钮显示当前项，列表可按分组标题列出并附说明；方向键、Home/End、Enter/空格与原生一致，Esc 与系统 Back 只收起列表，不关闭所在弹窗。

弹窗内的长表单（如[模型连接](MODELS.md)的服务商表单）按节分组，节标题下用分隔线隔开；成对的短字段并排，窄于 520px 时合为一列；可选项收进「高级选项」；保存与返回固定在弹窗底部，滚动时始终可见。从服务获取的长列表用可筛选的勾选列表，不用下拉框。

普通弹窗打开后，若浏览器自动聚焦关闭按钮，则将初始焦点移到标题；标题不进入 Tab 顺序。关闭按钮默认透明无框，悬停显示背景反馈，Tab 聚焦保留橙色焦点环；已聚焦的表单控件和无标题详情弹窗保留原行为。

弹窗通过发起事件记录返回控件，兼容点击后按钮未获焦点的 WebKit 行为；菜单操作返回稳定的菜单按钮，嵌套弹窗分别记录各自发起控件。关闭时优先返回仍连接且可见的发起控件；删除发起控件后，在仍打开的最上层详情弹窗内选择可操作按钮，无弹窗时回到工作区首个可见且启用的按钮，不穿过隐藏区或下层模态。

小于 768px 时，Agent 列表和会话单页切换；返回按钮回到列表。手机会话使用阅读式排版：对方消息不加气泡、以衬线体 16px 显示并在上方标注名称，自己的消息为右侧圆角气泡；不显示头像和悬停/右键消息操作，输入栏为悬浮胶囊加 40px 圆形发送按钮，聚焦时同样只让边缘变亮。详情使用带深色遮罩的模态浮层，焦点保留在浮层内，关闭后返回发起控件。中等宽度将详情浮在工作区侧边。列表、消息和详情分别滚动，触控操作至少 44 CSS px。

Android 开发候选的系统 Back 先收起 IME，再关闭顶层菜单/下拉列表/弹窗、退出管理页回到工作区，最后执行工作区返回；默认 Agent 会话返回列表并聚焦相应角色，未发送草稿保留。工作区根层才交回系统退出。公开入口和当前交付差异见 [Android 系统 Back](ANDROID.md#系统-back)。

## 菜单、外观与扩展管理

macOS采用48px一体化顶栏，保留原生红绿灯，手机端品牌旁显示当前会话名称；桌面端由会话头部显示角色与会话标题，顶栏不重复。系统按钮使用主窗口的trafficLightPosition配置，本机原生测量中心距顶端24px，见[Mac核对](../evidence/MAC-TITLEBAR-2026-10-17.md)。顶栏不显示运行环境或阶段标签。主题、菜单及侧栏按钮默认透明，悬停和按下显示反馈。

顶栏自定义菜单提供扩展管理、角色卡设置、应用设置和关于；诊断工具只在开发构建出现。角色卡设置集中提供角色选择、名称与说明编辑、文件导入、来源和能力查看；内容由 `ui.agents` 的公开 `role-settings` 视图提供，外壳只负责模态挂载。应用设置按“名称—操作”的行排列：界面布局与外观主题为分段按钮，颜色模式、管理扩展和诊断各一个按钮，不使用系统下拉菜单。默认界面不显示角色、对话、扩展标签，也不显示工作台/画布选择栏；原实验工作台、画布与逆序服务只在开发构建的目录中，可从诊断启动，再从设置选择；发布包只保留内置文本处理工作台。

界面以梅子品牌图标为视觉起点，浅色使用白底橙色图标，深色自动切换为黑底橙色图标（`/brand/plums-dark.png`）。浅色采用`#FFFFFF`主背景、`#F7F7F8`顶栏、`#F6F6F7`侧栏、`#EDEDF0`弱表面、`#E2E2E7`侧栏选中态、`#1A1A1A`主文字；深色采用`#171718`主背景、`#1F1F20`顶栏、`#1E1E1F`侧栏、`#252525`卡片、`#2A2A2C`浮层与输入栏、`#2C2C2F`侧栏悬停态、`#343438`侧栏选中态和`#E8E8E8`主文字。两种主题保持`#F57D4A`橙色主操作。移动端（`<= 767px`）改用 Claude 配色（`src/mobile-theme.css`）：浅色`#F5F4ED`羊皮纸背景、`#FAF9F5`卡片与浮层、`#E8E6DC`弱表面与边框、`#141413`主文字、`#C96442`赤陶主操作（其上文字`#141413`）；深色`#141413`背景、`#242423`卡片、`#30302E`浮层与边框、`#FAF9F5`主文字、`#D97757`主操作；标题使用`--font-serif`衬线体。手动主题贡献以内联变量写入根节点，仍优先于这套默认配色。桌面端采用紧凑的 13–14px 排版与 32–36px 控件高度，移动端（`<= 767px`）保持至少 44 CSS px 触控目标。按钮、线性图标、输入、菜单和弹窗共用语义变量。浮层使用 10–12px 圆角，标题、内容和操作区分层；悬停变化背景与细边，键盘操作显示焦点环；最近一次操作为点按或点击时（根节点 `data-input="pointer"`），按钮不显示焦点环，避免弹窗或菜单关闭后归还焦点时出现橙框。授权弹窗与通用弹窗打开时焦点落在标题。尊重减少动态效果偏好。

首次外观取系统设置；手动主题、布局和导入模块路径经串行 `host.shell` 保存；本地角色/会话由 `agents.local` 存于自身状态。新保存的布局记录 `layoutIntent: explicit`；旧配置仅在布局为 `default`、无显式来源且无已存组合时采用 Agent 起始界面，启动不自动覆写存档，下一次成功保存才提交新偏好。带显式来源、已存组合或其他布局 ID 的偏好继续保留，真实失效仍提供诊断。视图挂载失败时回退到最近可用界面或保留原偏好标识，不写入空布局；解析到空布局按默认界面处理。平台初始化失败在启动提示和对应管理区域显示原因与重新加载指引，只有明确探测为不支持才显示“平台不支持”。写入失败保留已确认状态，未知写入回执要求重新加载后再修改。损坏或未知配置拒绝覆盖。消息恢复仅接受字符串 `user` 或 `agent`，数组等错误角色类型使 `agents.local` 启动失败并保留原数据，不自动转换；应用其余部分照常可用。桌面窗口与 Android 系统栏通过 `shell_set_theme` 同步；Android 系统栏、缺口及键盘 Insets 来自受控模板，详见 [Android 工程](ANDROID.md)。

扩展管理列表的卡片只显示名称、状态、ID 与版本、使用者数量和操作；点选卡片在详情中显示使用者、模块位置、服务、权限、资源和任务。桌面详情在右侧，单列宽度下展开在所选卡片内。从 Agent 详情的扩展气泡进入时直接选中并滚动到该扩展。安装对话框先提示只导入可信来源的文件，可点按钮选择或拖入单个 .js 文件（触屏不显示拖放提示）（桌面窗口关闭了 Tauri 拖放拦截，交给页面处理）；读取后显示 ID、版本、服务、权限、联网目标与来源哈希，确认导入后保持停用，同 ID 显示为“替换”。开发者仍可按模块路径安装（发布构建中折叠在“开发者”下）：入口加载同源可信 ESM 并保存模块路径；加载代码会执行，加载后仍需单独检查和启用，安装路径与启用意图自动恢复；能力授权按扩展版本保留，版本变化后须重新确认。保存的模块加载失败时保留外壳与数据，管理页允许重试或移除路径；同 ID 重新安装会替换失效路径。能力确认框允许取消或 Escape；确认后才授予并启动。停用后释放资源，清理失败保留诊断并禁止重启。管理页采用固定页头与独立滚动内容：返回键和安装入口保持可达，列表及详情在下方滚动。管理页隐藏不等于停用业务，保留工作区挂载。

## 文本处理工作台

仅开发构建提供。从扩展管理启用 `ui.workbench-board` 并确认隔离状态读写权限，可在 Agent 会话与非聊天工作台之间切换。工作台提供处理项筛选、编辑执行、取消、草稿保存、结果列表和详情；桌面详情分栏，手机详情为带焦点返回的模态层。页面动态登记、偏好与恢复、公开宿主入口和作者用法见 [页面契约](PAGES.md)。

## 所有权与公开契约

`ui.agents` 使用公开 `ctx.view` 挂载；`agents.local` 通过普通版本服务 `agents@1` 提供业务，`ui.agents` 以 `ctx.use` 获取，没有给通用内核或 SDK 新增聊天 API。`agents@1` 的 `Message.at` 记录发送或回复时间（毫秒，旧消息可缺省）；可选的 `removeMessage(id, sessionId, messageId)` 删除单条已保存消息，处理中拒绝，提供者未实现时界面不显示删除。默认 UI 读取提供者的公开快照、订阅、操作和来源说明，不访问其私有状态，并保留普通类方法的接收对象。第三方提供者可替换该服务，也可贡献完全不同的 UI。

会话标题、当前 Agent 的扩展所有者和默认详情的真实状态通过当前视图的可选 `View.chrome` 发布。外壳优先选择当前实体扩展的侧栏，其次为工作区扩展侧栏，最后使用默认详情；上下文侧栏与默认 inline 详情保持互斥。移动模态详情转为桌面时重新协调。Agent 详情的「组成扩展」逐行列出提供者自身（始终开启）与每个已启用的文本服务，点按名称进入扩展管理并选中，行尾开关为此 Agent 开启或关闭该服务；开启多个时注明处理顺序，全部关闭时提示暂时无法回复。扩展管理只显示扩展经 `ctx.shell.publishUsers` 公布的使用者，不读取 Agent 数据：可开关的扩展列出全部 Agent，实心带勾为开启、虚线为关闭，点按切换；停用仍有使用者的扩展前弹出确认并列出它们，开关在重新启用后恢复；`WorkspaceChrome.navigation` 仍是 SDK 中的实验字段，外壳暂无消费者。状态所有权与模块入口见 [前端架构](ARCHITECTURE.md#当前前端的状态所有权)。

React视图每次挂载创建独立节点；释放先移除该节点，跨微任务卸载root并向Host返回清理Promise，避免外壳提交期间同步卸载或旧释放清空替换视图。Agent工作区节点继续填满可用高度，角色设置节点保持自然高度；长会话滚动和交叠替换/订阅释放由 `react-view-lifecycle.spec.ts` 覆盖。

Agent 界面的组合、弹窗、卡片草稿与后备焦点位于 [src/agents](../src/agents/)。弹窗组件随工作区常驻，关闭仅移除 Dialog，保留创建说明、多会话选择及卡片输入；成功添加后沿用原重置规则。媒体查询在 Hook 内创建和订阅，模块导入不访问 matchMedia；限定回归见 [C1 证据](../evidence/MAINTENANCE-2026-10-17.md#c1agent-工作区职责拆分)。

角色、会话、文本处理与卡片解析位于扩展层；`src/application.ts` 接线默认组合、内置授权与旧数据迁移，通用外壳只保存不透明业务字段。Agent/会话存于 `extension.agents.local`；文本处理工作台通过自身 `ctx.platform` 另存于 `extension.ui.workbench-board`，页面贡献的业务数据归各贡献者管理。每个状态快照均受现有 64 KiB 限制；长期存储与通用升级迁移尚未实现。特别关注直接保存为每个 Agent 的 `pinned` 字段，避免维护第二份 ID 列表。

外壳保留扩展管理、授权与无布局恢复入口。启用提供新视图的扩展时优先选中其视图；用户可在设置切回。`ui.default` 与 `ui.board` 保留公开挂载路径。挂载失败排除该代视图并回退到可用界面；无布局时展示宿主恢复入口；未安装文本工作台实验的组合仅提供扩展管理，不展示该实验的授权启动按钮。无 `agents` 服务的独立组合可照常启动、管理与恢复。共享 WebView 的可信模式不构成防恶意代码或界面伪装的沙箱。

## 手动安装扩展卸载

扩展管理为手动安装项提供“卸载（保留数据）”，确认框说明依赖等待和数据保留。内置项只停用。成功后从目录和持久化安装路径移除并把焦点返回管理标题；取消返回发起按钮。清理/撤权/保存失败留在确认框，扩展可能已停用，须重试或重载确认；未知保存回执不允许继续写配置。扩展状态与模块文件不删除，同 ID 重装重新授权。

## 组合与提示

启用、停用和授权自动记录，下次启动恢复，不提供手动保存按钮；同一扩展已授予的能力不再重复弹出授权框。写入失败用错误提示说明，不增加弹窗或新的导航层。

操作结果与错误以顶部居中的浮层提示显示，不需要手动关闭：按文字长度停留 3–10 秒后淡出，指针悬停时保持；新消息替换旧消息。需要用户操作的提示（如所选界面不可用的“查看原因”）仍为常驻横幅。坏组合结构由启动错误提示提供“恢复默认组合”，确认说明备份与数据保留；取消回到触发按钮，成功/失败关闭后聚焦重新加载。详见 [组合契约](COMPOSITION.md)。
