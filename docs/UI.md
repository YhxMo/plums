# 默认界面与跨端体验

[架构](ARCHITECTURE.md) · [扩展契约](EXTENSION-CONTRACTS.md) · [验证证据](../evidence/RESULTS.md)

## 从添加 Agent 开始

0.0.4 默认显示 Agent 界面。零角色时显示品牌和“导入角色卡／安装扩展”两张引导卡，底部保留“从头添加 Agent”次要入口。已有角色但未选中时，桌面左侧保留列表，右侧只显示居中的低干扰 Plums 图标；角色是否接入模型不影响计数。选中角色后显示会话。手机无角色时显示上下排列的引导卡，已有角色时先显示列表，选中后进入会话。两端均可从“添加”进入添加方式菜单，创建角色、导入角色卡或查看扩展。模型连接器与 MCP 属于扩展能力，在扩展管理中接入。

当前内置提供者只执行本地文本转换，支持角色说明和独立会话，不包含语言模型或 MCP 客户端。添加表单显示实际提供者说明；导入角色卡不会改变执行能力或授予访问权限。实验 JSON 卡片需要 `name`，可选 `description`、`multiSession` 和 `version: 1`。支持选择本地文件、粘贴 JSON 或读取应用同源链接；外部链接需先下载文件，原生 CSP 保持原边界。此格式由扩展层解析，不是完整角色卡标准或 A2A 协议。

同源角色卡链接读取拒绝重定向，最多读取 32000 个 UTF-8 字节，10 秒内未完成则报超时；关闭或取消会中止读取，失败保留原输入。文件入口也限制 32000 字节。

## 列表、交互与详情

桌面布局为256px Agent列表、可伸缩会话区、可折叠的268px详情栏。默认右侧详情四角14px圆角，上、右、下各留10px；外侧占宽278px。列表提供搜索和添加；特别关注的 Agent 以头像快捷区和星标显示，仍可从全部列表进入。操作菜单支持鼠标、右键、触屏长按及键盘，包含特别关注、重命名、移除。删除前确认本地会话的删除范围。

点击角色进入会话。消息按发送方左右排列；底部输入框保持可用，处理中显示停止操作。写入派发后进入不可撤回的提交段，显示等待保存并禁用停止；成功回执优先。成功保存后清除对应草稿；失败和提交前取消保留草稿与上次保存的消息。本地服务回复在保存前验证字符串类型及 32,000 个 UTF-16 代码单元上限；总快照仍受 64 KiB 限制。桌面 Enter 发送、Shift+Enter 换行，输入法组词期间不发送；手机通过发送按钮提交。

详情栏展示人类可读的角色说明、实际能力、来源与版本、状态和特别关注。支持多会话的角色在这里新建、切换和删除会话；处理期间先停止任务再管理会话。删除最后一个会话后保留一个新的空会话。每个 Agent/会话拥有独立草稿。

普通弹窗打开后，若浏览器自动聚焦关闭按钮，则将初始焦点移到标题；标题不进入 Tab 顺序。关闭按钮默认透明无框，悬停显示背景反馈，Tab 聚焦保留橙色焦点环；已聚焦的表单控件和无标题详情弹窗保留原行为。

弹窗通过发起事件记录返回控件，兼容点击后按钮未获焦点的 WebKit 行为；菜单操作返回稳定的菜单按钮，嵌套弹窗分别记录各自发起控件。关闭时优先返回仍连接且可见的发起控件；删除发起控件后，在仍打开的最上层详情弹窗内选择可操作按钮，无弹窗时回到工作区首个可见且启用的按钮，不穿过隐藏区或下层模态。

小于 768px 时，Agent 列表和会话单页切换；返回按钮回到列表。详情使用带深色遮罩的模态浮层，焦点保留在浮层内，关闭后返回发起控件。中等宽度将详情浮在工作区侧边。列表、消息和详情分别滚动，触控操作至少 44 CSS px。

## 菜单、外观与扩展管理

macOS采用48px一体化顶栏，保留原生红绿灯，品牌旁显示当前会话名称；桌面会话区不重复标题。系统按钮使用主窗口的trafficLightPosition配置，本机原生测量中心距顶端24px，见[Mac核对](../evidence/MAC-TITLEBAR-2026-10-17.md)。顶栏不显示运行环境或阶段标签。主题、菜单及侧栏按钮默认透明，悬停和按下显示反馈。

顶栏自定义菜单提供扩展管理、角色卡设置、应用设置、诊断工具和关于。角色卡设置集中提供角色选择、名称与说明编辑、文件导入、来源和能力查看；内容由 `ui.agents` 的公开 `role-settings` 视图提供，外壳只负责模态挂载。应用设置展示已启用的布局按钮，不使用系统下拉菜单。默认界面不显示角色、对话、扩展标签，也不显示工作台/画布选择栏；原实验工作台和画布可从诊断启动，再从设置选择。

界面以梅子品牌图标为视觉起点，浅色使用白底橙色图标，深色自动切换为黑底橙色图标（`/brand/plums-dark.png`）。浅色采用`#FFFFFF`主背景、`#F7F7F8`顶栏、`#F6F6F7`侧栏、`#EDEDF0`弱表面、`#E2E2E7`侧栏选中态、`#1A1A1A`主文字；深色采用`#171718`主背景、`#1F1F20`顶栏、`#1E1E1F`侧栏、`#252525`卡片、`#2A2A2C`浮层与输入栏、`#2C2C2F`侧栏悬停态、`#343438`侧栏选中态和`#E8E8E8`主文字。两种主题保持`#F57D4A`橙色主操作。桌面端采用紧凑的 13–14px 排版与 32–36px 控件高度，移动端（`<= 767px`）保持至少 44 CSS px 触控目标。按钮、线性图标、输入、菜单和弹窗共用语义变量。浮层使用 10–12px 圆角，标题、内容和操作区分层；悬停变化背景与细边，键盘操作显示焦点环，并尊重减少动态效果偏好。

首次外观取系统设置；手动主题、布局、本地角色/会话和导入模块路径经串行 `host.shell` 保存。新保存的布局记录 `layoutIntent: explicit`；旧配置仅在布局为 `default`、无显式来源且无已存组合时采用 Agent 起始界面，启动不自动覆写存档，下一次成功保存才提交新偏好。带显式来源、已存组合或其他布局 ID 的偏好继续保留，真实失效仍提供诊断。写入失败保留已确认状态，未知写入回执要求重新加载后再修改。损坏或未知配置拒绝覆盖。消息恢复仅接受字符串 `user` 或 `agent`，数组等错误角色类型阻止恢复并保留原数据，不自动转换。桌面窗口与 Android 系统栏通过 `shell_set_theme` 同步；Android 系统栏、缺口及键盘 Insets 来自受控模板，详见 [Android 工程](ANDROID.md)。

扩展管理显示 manifest 的身份、版本、原生能力、依赖、资源和任务。安装入口加载同源可信 ESM 并保存模块路径；加载代码会执行，加载后仍需单独检查和启用，安装路径可恢复，保存组合后可恢复启用意图；能力授权保持会话级，仍须重新确认。保存的模块加载失败时保留外壳与数据，管理页允许重试或移除路径；同 ID 重新安装会替换失效路径。能力确认框允许取消或 Escape；确认后才授予并启动。停用后释放资源，清理失败保留诊断并禁止重启。管理页采用固定页头与独立滚动内容：返回键、安装和保存组合入口保持可达，列表及详情在下方滚动。管理页隐藏不等于停用业务，保留工作区挂载。

## 文本处理工作台

从扩展管理启用 `ui.workbench-board` 并确认隔离状态读写权限，可在 Agent 会话与非聊天工作台之间切换。工作台提供处理项筛选、编辑执行、取消、草稿保存、结果列表和详情；桌面详情分栏，手机详情为带焦点返回的模态层。页面动态登记、偏好与恢复、公开宿主入口和作者用法见 [页面契约](PAGES.md)。

## 所有权与公开契约

`ui.agents` 使用公开 `ctx.view` 挂载；`agents.local` 通过普通版本服务 `agents@1` 提供业务。SDK 的 `withAgents(ctx)` 提供可选 `ctx.agents` facade，底层仍是 `ctx.use`，没有给通用内核新增聊天 API。默认 UI 读取提供者的公开快照、订阅、操作和来源说明，不访问其私有状态，并保留普通类方法的接收对象。第三方提供者可替换该服务，也可贡献完全不同的 UI。

会话标题、当前 Agent 的扩展所有者和默认详情的真实状态通过当前视图的可选 `View.chrome` 发布。外壳优先选择当前实体扩展的侧栏，其次为工作区扩展侧栏，最后使用默认详情；上下文侧栏与默认 inline 详情保持互斥。移动模态详情转为桌面时重新协调。管理页的 Agent 跳转只发送给声明 `agents.agent` 的工作区，其他工作区显示不可用原因。状态所有权与模块入口见 [前端架构](ARCHITECTURE.md#当前前端的状态所有权)。

React视图每次挂载创建独立节点；释放先移除该节点，跨微任务卸载root并向Host返回清理Promise，避免外壳提交期间同步卸载或旧释放清空替换视图。Agent工作区节点继续填满可用高度，角色设置节点保持自然高度；长会话滚动和交叠替换/订阅释放由 `react-view-lifecycle.spec.ts` 覆盖。

角色、会话、文本处理与卡片解析位于扩展层；应用外壳只装配内置组合并提供通用持久化回调。Agent/会话与宿主偏好暂共用 `host.shell` 小快照；文本处理工作台通过自身 `ctx.platform` 另存于 `extension.ui.workbench-board`，页面贡献的业务数据归各贡献者管理。每个状态快照均受现有 64 KiB 限制；长期存储与通用升级迁移尚未实现。特别关注直接保存为每个 Agent 的 `pinned` 字段，避免维护第二份 ID 列表。

外壳保留扩展管理、授权与无布局恢复入口。启用提供新视图的扩展时优先选中其视图；用户可在设置切回。`ui.default` 与 `ui.board` 保留公开挂载路径。挂载失败排除该代视图并回退到可用界面；无布局时展示宿主恢复入口。共享 WebView 的可信模式不构成防恶意代码或界面伪装的沙箱。

颜色变量在 `src/styles.css`，布局样式在各组件模块；默认 Agent、工作台与画布共享语义变量。图标源为 `src-tauri/icons/source.png`，`npm run icons` 生成 Mac、Android 与 Web 资源。公开 `ctx.theme` 可贡献这17个语义色，应用设置选择、停用回退和保存规则见 [主题契约](THEMES.md)。原生窗口/系统栏只跟随明暗模式，未扩展到任意原生颜色。内置CSS为恢复后备；这是实验契约，尚非稳定主题或 Agent SDK。

## 手动安装扩展卸载

扩展管理为手动安装项提供“卸载（保留数据）”，确认框说明依赖等待和数据保留。内置项只停用。成功后从目录和持久化安装路径移除并把焦点返回管理标题；取消返回发起按钮。清理/撤权/保存失败留在确认框，扩展可能已停用，须重试或重载确认；未知保存回执不允许继续写配置。扩展状态与模块文件不删除，同 ID 重装重新授权。

## 组合保存

扩展管理提供“保存当前组合”，说明替换上一快照、下次启动恢复和权限重新确认。保存使用已有忙碌/错误/成功反馈；不增加弹窗或新的导航层。预检失败仍保留宿主管理入口；坏组合结构由启动错误提示提供“恢复默认组合”，确认说明备份与数据保留；取消回到触发按钮，成功/失败关闭后聚焦重新加载。详见 [组合契约](COMPOSITION.md)。

## 非敏感扩展配置

扩展管理支持声明字段编辑、取消焦点返回和保存后应用；操作区采用可换行布局。生命周期、坏值保留与迁移限制见 [配置契约](EXTENSION-CONFIGURATION.md)，限定验证见 [配置证据](../evidence/CONFIGURATION-2026-10-15.md)。

可选 [固定视图树助手](VIEW-TREE.md) 已完成两作者内部样板与两端限定验收。普通工作台已通过页面路由使用固定树；新增页面在移动列表页也可从顶部导航进入，固定树挂载完成后仍禁止追加节点。动态增减在路由层重建整页，跨作者嵌套与依赖停止见接入证据。
