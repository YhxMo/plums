# 默认界面与跨端体验

[架构](ARCHITECTURE.md) · [扩展契约](EXTENSION-CONTRACTS.md) · [验证证据](../evidence/RESULTS.md)

## 从添加 Agent 开始

0.0.4 默认显示 Agent 界面。没有角色时，桌面保留空白 Agent 列表，中间显示“导入角色卡”和“安装扩展”两张引导卡；手机将引导卡上下排列。两端均可从“添加”进入添加方式菜单，创建角色、导入角色卡或查看扩展。模型连接器与 MCP 属于扩展能力，在扩展管理中接入。

当前内置提供者只执行本地文本转换，支持角色说明和独立会话，不包含语言模型或 MCP 客户端。添加表单显示实际提供者说明；导入角色卡不会改变执行能力或授予访问权限。实验 JSON 卡片需要 `name`，可选 `description`、`multiSession` 和 `version: 1`。支持选择本地文件、粘贴 JSON 或读取应用同源链接；外部链接需先下载文件，原生 CSP 保持原边界。此格式由扩展层解析，不是完整角色卡标准或 A2A 协议。

同源角色卡链接读取拒绝重定向，最多读取 32000 个 UTF-8 字节，10 秒内未完成则报超时；关闭或取消会中止读取，失败保留原输入。文件入口也限制 32000 字节。

## 列表、交互与详情

桌面布局为 280px Agent 列表、可伸缩会话区、可折叠的 290px 详情栏。列表提供搜索和添加；特别关注的 Agent 以头像快捷区和星标显示，仍可从全部列表进入。操作菜单支持鼠标、右键、触屏长按及键盘，包含特别关注、重命名、移除。删除前确认本地会话的删除范围。

点击角色进入会话。消息按发送方左右排列；底部输入框保持可用，处理中显示停止操作。写入派发后进入不可撤回的提交段，显示等待保存并禁用停止；成功回执优先。成功保存后清除对应草稿；失败和提交前取消保留草稿与上次保存的消息。本地服务回复在保存前验证字符串类型及 32,000 个 UTF-16 代码单元上限；总快照仍受 64 KiB 限制。桌面 Enter 发送、Shift+Enter 换行，输入法组词期间不发送；手机通过发送按钮提交。

详情栏展示人类可读的角色说明、实际能力、来源与版本、状态和特别关注。支持多会话的角色在这里新建、切换和删除会话；处理期间先停止任务再管理会话。删除最后一个会话后保留一个新的空会话。每个 Agent/会话拥有独立草稿。

弹窗通过发起事件记录返回控件，兼容点击后按钮未获焦点的 WebKit 行为；菜单操作返回稳定的菜单按钮，嵌套弹窗分别记录各自发起控件。关闭时仅在该控件仍连接到文档时恢复焦点；成功删除发起控件的情况尚无专门的后备焦点策略。

小于 768px 时，Agent 列表和会话单页切换；返回按钮回到列表。详情使用带深色遮罩的模态浮层，焦点保留在浮层内，关闭后返回发起控件。中等宽度将详情浮在工作区侧边。列表、消息和详情分别滚动，触控操作至少 44 CSS px。

## 菜单、外观与扩展管理

顶栏自定义菜单提供扩展管理、角色卡设置、应用设置、诊断工具和关于。角色卡设置集中提供角色选择、名称与说明编辑、文件导入、来源和能力查看；内容由 `ui.agents` 的公开 `role-settings` 视图提供，外壳只负责模态挂载。应用设置展示已启用的布局按钮，不使用系统下拉菜单。默认界面不显示角色、对话、扩展标签，也不显示工作台/画布选择栏；原实验工作台和画布可从诊断启动，再从设置选择。

界面以白底橙色梅子图标为视觉起点。浅色采用 `#FAFAFA` 背景、白色表面、`#EDEDED` 边界、`#1A1A1A` 主文字和 `#F57D4A` 主操作；深色沿用暖炭灰表面和柔和橙色。按钮、线性图标、输入、菜单和弹窗共用语义变量。浮层使用 12px 圆角，标题、内容和操作区分层；悬停变化背景与细边，键盘操作显示焦点环，并尊重减少动态效果偏好。

首次外观取系统设置；手动主题、布局、本地角色/会话和导入模块路径经串行 `host.shell` 保存。写入失败保留已确认状态，未知写入回执要求重新加载后再修改。损坏或未知配置拒绝覆盖。消息恢复仅接受字符串 `user` 或 `agent`，数组等错误角色类型阻止恢复并保留原数据，不自动转换。桌面窗口与 Android 系统栏通过 `shell_set_theme` 同步；Android 系统栏、缺口及键盘 Insets 来自受控模板，详见 [Android 工程](ANDROID.md)。

扩展管理显示 manifest 的身份、版本、原生能力、依赖、资源和任务。安装入口加载同源可信 ESM 并保存模块路径；加载代码会执行，加载后仍需单独检查和启用，启动时不恢复外部扩展的授权和启用状态。保存的模块加载失败时保留外壳与数据，管理页允许重试或移除路径；同 ID 重新安装会替换失效路径。能力确认框允许取消或 Escape；确认后才授予并启动。停用后释放资源，清理失败保留诊断并禁止重启。管理页隐藏不等于停用业务，保留工作区挂载。

## 所有权与公开契约

`ui.agents` 使用公开 `ctx.view` 挂载；`agents.local` 通过普通版本服务 `agents@1` 提供业务。SDK 的 `withAgents(ctx)` 提供可选 `ctx.agents` facade，底层仍是 `ctx.use`，没有给通用内核新增聊天 API。默认 UI 读取提供者的公开快照、订阅、操作和来源说明，不访问其私有状态，并保留普通类方法的接收对象。第三方提供者可替换该服务，也可贡献完全不同的 UI。

角色、会话、文本处理与卡片解析位于扩展层；应用外壳只装配内置组合并提供通用持久化回调。业务数据暂与外观保存在一个小规模隔离快照中，受现有 64 KiB 限制；长期存储及迁移尚未设计。特别关注直接保存为每个 Agent 的 `pinned` 字段，避免维护第二份 ID 列表。

外壳保留扩展管理、授权与无布局恢复入口。启用提供新视图的扩展时优先选中其视图；用户可在设置切回。`ui.default` 与 `ui.board` 保留公开挂载路径。挂载失败排除该代视图并回退到可用界面；无布局时展示宿主恢复入口。共享 WebView 的可信模式不构成防恶意代码或界面伪装的沙箱。

颜色变量在 `src/styles.css`，布局样式在各组件模块；默认 Agent、工作台与画布共享语义变量。图标源为 `src-tauri/icons/source.png`，`npm run icons` 生成 Mac、Android 与 Web 资源。这是实验约定，尚非稳定主题或 Agent SDK。

## 验收与覆盖

负责人为应用实现维护者，独立审查由未参与实现的执行者承担。验收覆盖 A3、A5–A8、A10、A12 的 M1 子集；具体版本与平台结果见证据。

| 路径 | 可证伪条件 | 覆盖入口 |
| --- | --- | --- |
| 添加、特别关注、会话与恢复 | 配置丢失、会话串线、删最后会话后无法使用、坏卡覆盖原数据 | `agents.test.ts`、`agent-flow.spec.ts` |
| 保存、失败、取消与草稿 | 未保存便清空输入、迟到结果覆盖取消、重试重复消息 | Agent 单元/浏览器测试；既有回执测试 |
| 外部提供者与界面替换 | 默认 UI 读取私有状态、外部提供者显示内置来源、替换后无法管理 | `agent-flow.spec.ts`、`workbench.spec.ts`、`dependency-chain.spec.ts` |
| 查看扩展→授权→运行→状态→停止/恢复 | 未确认便授权、取消仍启用、停用残留资源/任务、恢复丢已存结果 | `application-flow.spec.ts`；宿主与平台测试 |
| 深浅外观、窄屏、键盘与浮层 | 主题丢草稿、页面溢出、详情焦点越界、原生键盘遮住输入 | `theme.spec.ts`、移动详情测试、实际截图与原生运行 |

复用已有服务替换、撤权、清理失败及损坏状态覆盖，只补缺失路径。浏览器、Mac 包和 Android 模拟器分别留证。真机、iOS、Windows/Linux、多 Agent 协作、完整角色卡标准与递归 UI 组合尚未验证；iOS 继续暂缓。

## 手动安装扩展卸载

扩展管理为手动安装项提供“卸载（保留数据）”，确认框说明依赖等待和数据保留。内置项只停用。成功后从目录和持久化安装路径移除并把焦点返回管理标题；取消返回发起按钮。清理/撤权/保存失败留在确认框，扩展可能已停用，须重试或重载确认；未知保存回执不允许继续写配置。扩展状态与模块文件不删除，同 ID 重装重新授权。

## 组合保存

扩展管理提供“保存当前组合”，说明替换上一快照、下次启动恢复和权限重新确认。保存使用已有忙碌/错误/成功反馈；不增加弹窗或新的导航层。预检失败仍保留宿主管理入口；坏组合结构由启动错误提示提供“恢复默认组合”，确认说明备份与数据保留；取消回到触发按钮，成功/失败关闭后聚焦重新加载。详见 [组合契约](COMPOSITION.md)。
