# M2 原生异常回执与预约恢复阶段归档

状态：2026-10-15 UTC 限定完成。负责人：SDK 与平台维护者；独立执行者完成源码与证据审查。M2 整体未完成。

范围：默认关闭的无凭据回环传输实验；目标是未知 prepare 回执与 cancel 失败不永久耗尽预约，不把未知副作用报成功。先用失败测试证明旧预约永久残留，再加入未执行预约 1000ms 租期、后续命令惰性回收和固定故障入口。已开始请求维持 800ms 总时限。没有生产网络、凭据或真实账户变更。

退出结果：Mac 实验包与 Android API 36 ARM64 隔离模拟器分别通过九类异常场景，实际窗口/服务计数验证回执未知、取消前后失败、跨 owner 拒绝、过期执行拒绝、16 项限额与恢复。175 前端单元、12 实验 Rust、6 默认 Rust、构建/格式/Clippy 通过。源码与产物绑定、具体命令及限制见 [证据](../../../evidence/TRANSPORT-FAULT-2026-10-15.md)和[设计](M2-native-transport-experiment-2026-10-15.md#异常回执)。

独立审查无阻塞；精简检查保留直接路径，无新增后台清理框架。普通 release 完整性核验不变；测试进程、映射已清理，原应用与开发服务保留。精确暂存隐私检查后仅本地提交，不推送。

限制：惰性回收不等于后台准时释放；未知回执为可控原生返回错误，不证明永久无回执/进程崩溃/休眠场景。生产能力、真实权限与其他平台门槛不因此通过。后续安排见 [当前计划](../milestone.md)及[整体优先级](../total.md#m2-剩余工作优先级)。
