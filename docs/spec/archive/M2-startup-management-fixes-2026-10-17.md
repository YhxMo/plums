# M2 启动界面与管理返回修复（已完成）

完成日期：2026-10-17（Asia/Shanghai）。应用维护者负责实现与两端验收，未参与实现的审查者独立复核。范围为历史默认布局恢复、已有 Agent 的品牌占位和管理页固定返回，沿用其他已确认 UI。

| 验收对象 | 结果 |
| --- | --- |
| 默认启动及兼容 | 首次/无组合且无显式记录的旧 default 进入 Agent；启动不写原存档，后续成功保存保留角色/会话。显式布局、其他布局及已存组合保持各自恢复/诊断语义 |
| Agent 三种状态 | 零 Agent 保留欢迎双卡片；已有 Agent 未选中时桌面右侧只有居中品牌，手机先列表；选中后进入会话 |
| 固定管理页头 | 两端浅深主题实际滚动后可直接返回且草稿保留；手机返回目标原生确认为44×44，桌面保持32×32 |
| 回归与交付 | 失败用例先复现；274 单元、最终110 浏览器通过，普通 Mac/Android 受影响路径、冷恢复与独立审查通过，同源受验原包进入 release，旧完整目录保留 |

实现、命令、平台、源码绑定、实际截图和归档路径见[修复证据](../../../evidence/UI-STARTUP-2026-10-17.md)。Rust/平台适配及未受影响路径按原专项证据复用；Android真机/其他配置、iOS、Windows/Linux、完整辅助技术及正式分发仍待验。M2整体未退出。
