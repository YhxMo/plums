## 目标与退出结果

| 可证伪验收 | 结果 |
| --- | --- |
| 两端构建并实际运行 reqwest + rustls 平台验证器候选 | 独立 Mac 可执行文件与 API36 ARM64 probe APK 通过，默认应用不启用实验 |
| 临时根下有效、未知根、错名、过期与撤去信任路径 | 两端各五项通过；Android 正式 AAR 不接受应用测试根的首次反例保留，最终正例使用官方进程内测试库 |
| Android JNI 假字节读取、失败、清理与恢复 | Rust 创建线程附加 JVM，六项通过；不触碰实际秘密库或向 WebView/网络返回秘密 |
| 根来源、依赖、许可、版本和限制 | 源码清单、产物摘要、依赖许可和根行为已登记，测试 companion 保留许可证原件 |
| 验证与独立审查 | 最终证据与独立审查通过，无剩余发现；Android Clippy 等未执行范围保留，不增加生产或未验平台结论 |

继续首选 Rust TLS/JNI，未触发整套 Kotlin 原生传输回退。OS 验证器可能独立获取 OCSP/CRL/根信息，须在 M2.3.4 前明确 DNS/路由/时限等强制边界，reqwest 配置不能代替证明。测试 mock 跳过的吊销路径、生产系统根正例、真实秘密和 Tauri 句柄适配未验。

本阶段使用假秘密，不改系统信任库、真实秘密库或 release，不推送。M2.3.2/M2.3.3 等后续实施未开始，见[当前阶段](../milestone.md)；M2.3 与 M2 整体仍未退出。
