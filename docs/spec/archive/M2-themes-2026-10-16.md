## 范围与验收

本阶段提供实验性的公开主题颜色贡献、生命周期注册/释放、可诊断冲突和应用设置选择。沿用既有语义颜色变量，允许选择已启用主题，停用或失败后恢复内置外观；原生窗口只跟随明暗模式，不承诺原生控件使用扩展颜色。内置外观与管理入口始终可恢复。主题偏好随现有配置保存，扩展启用集合仍由现有组合机制保存。

可证伪验收：两位独立作者仅依公开 SDK 和说明提供主题；应用及非聊天视图显示选定颜色；重复 ID、非法颜色/字段、激活后失败、停用同步重入和旧 context 注册均拒绝或撤回；返回值和作者对象变更不能修改已登记颜色；选定主题停用/卸载后立即回退，重新启用按保存偏好恢复；偏好写入失败不伪报成功。320/375/768/1440px 检查管理入口、按钮、文本对比和无横向溢出。Mac arm64 与 Android API36 ARM64 模拟器分别运行专项测试包，使用隔离数据，保留现有应用/开发进程。

执行顺序：先以失败测试固定契约，再实现与独立接入、浏览器和原生专项验证、独立审查及必要精简复验，最后记录源码身份、精确暂存隐私检查、本地提交与完成归档。任一核心反例未关闭不得归档为完成。
