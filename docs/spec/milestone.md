## M2.3 平台能力切片

### 目标与拟新增路径

一个真实连接器通过 `text.transform@1` 接入现有 Agent；只发送当前文本，单次、非流式、非思考，不发送角色说明或历史。默认本地服务无需凭据，连接器不自动启用，切回保留数据。模型名在真实操作前核对，现有默认值只是代码现状。

```text
现有 Agent / 共享工作台 → text.transform@1 → connector.deepseek
  → ctx.platform("credential.request", { version, binding, body }, signal)
  → Host 声明/授权/生命周期检查 → PlatformAdapter
  → 拟新增原生请求入口 → 每绑定授权/修订/世代 → 原生秘密读取
  → 受限传输 → connector 解析 → 公开消费者
```

原生请求、授权、撤销的命令名尚未冻结；新入口属于计划，不是当前已注册命令。公开扩展 API 保持 version/binding/body；目标、头、代理和秘密由平台绑定管理。
