## 紧接准备：无业务视图事件服务的启动、暂停与重启

负责人：生命周期与 SDK 维护者。状态：准备，尚未实施验收。进入条件：限定前台/声明运行条件，使用现有公开 on/emit/task 与启停接口，先定义业务 UI 不挂载时的可观测状态、资源归属和失败判据，再核对是否需要补充最小契约。

可证伪验收：公开样板可在不挂载业务视图时接收事件并执行任务；暂停/停用后不再接收，合作式在途任务结束且监听释放；重启只恢复一个订阅；失败/资源不足可解释且管理入口仍可达。预先建立重复订阅、停止后调用及清理失败反例；仅在依赖满足后实现，分别保留单元、浏览器和必要原生证据，独立复审、精简、隐私检查及本地阶段提交后归档。

不以此前 UI 样板替代此阶段通过；移动长期后台、系统回收、常驻服务和进程模型不在此最小阶段内。
