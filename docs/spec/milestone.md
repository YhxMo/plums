## 阶段目标

DeepSeek 官方连接器通过公开 `text.transform@1` 接入现有 Agent，完成一次非流式、非思考的单次输入输出。默认模型 deepseek-flash、输出预算 256；Mac/Android 先验证官方 API 直连，保留明确配置的 HTTP(S) 网络代理，不自动读取系统/环境代理。API 中转/网关后续独立支持。

平台管理 owner/alias、每绑定批准的媒体类型/固定头/认证注入、进程授权世代、系统秘密、精确目标、DNS/TLS 限制、取消/撤销、时限和资源限额。扩展只提交 version/binding/body，负责模型参数、JSON 载荷与解析。具体契约见[生产接入](../CREDENTIAL-REQUEST.md#生产接入)。

已确认 UI 保持。连接器沿用公开服务替换流程，不默认启用；本地调用无凭据前置条件。真实接入需同步 Agent、共享工作台和关于页的实际来源/外发说明，保留旧角色、会话、草稿及本地入口。多轮历史、流式、工具调用、OAuth、MCP 和多 Agent 协作另分阶段。

## 验收与退出

失败验收见[适用反例](../CREDENTIAL-REQUEST.md#失败验收)：非法或冲突政策拒绝，政策修改使旧授权失效；跨 owner、未授权或停用时服务端零命中；旧世代不交付；重定向第二目标零命中；DNS/私网/TLS/代理限制生效；秘密库部分失败可核对且不降级明文；未知回执不自动重试；限额和总时限释放资源；令牌不进入日志或交付结果。

退出要求：真实连接器在现有 Agent 界面完成一次单次输入输出；来源与外发说明准确，失败/取消保留草稿，可明确切回本地；两端同源普通包完成绑定创建/撤销及适用失败路径，服务端观察与本地回执一致；恢复、独立审查及保留旧包交付有证据。

Android 真机/其他配置、iOS 最小实验、稳定 SDK 和正式分发仍按整体门槛执行。当前生产传输与实际秘密操作缺口继续保留，本阶段尚未退出。
