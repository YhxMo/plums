## 第一版之后

不进入第一版，按真实使用反馈排入后续各级：

- 会话分支切换（编辑后保留多个版本），由扩展实现。
- 对话压缩：接近上下文窗口时把较早轮次总结为摘要；连接器只负责预算内组装。
- 缓存用量可见：读取服务响应中的缓存命中 token，不凭请求参数推断。
- VoiceOver 验收与其余键盘路径。
- 外部独立作者试用。
- 第 2 级群聊的计划在第 1 级完成后编写。
