## 模型连接后续

在真实用户路径反馈之后按顺序推进：

1. **窗口自动填写的完整手测**：公开目录通过 `network.read` 读取且不带密钥；服务商模型列表使用对应凭据。核对按服务地址/厂商匹配、每模型窗口、未知模型回退。
2. **对话压缩扩展**：在接近窗口时把较早轮次总结为摘要，取代直接丢弃；通过公开扩展契约接入，连接器只负责预算内组装。
3. **长期记忆 `memory@1`**：跨会话事实由独立扩展管理，每个 Agent 自选启用。
4. **缓存用量可见**：读取服务响应中的缓存命中 token，在界面显示真实用量；不凭请求参数推断命中或费用。
