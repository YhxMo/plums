## 剩余可独立推进的有限候选

1. UI 导航确定性冲突与同进程停用回退已限定完成；主题/history/持久化不在此结果内。
2. 合成状态确认/失败展示界面已限定完成；真实业务接入、包事务与历史裁剪仍需另定范围。
3. 平台能力：先选一个真实扩展需要的操作，用合成资源完成权限/拒绝/未知结果契约和隔离适配，不配置真实凭据。

这三项是后续候选，不表示同时开工或全部 M2 缺口。需要决定：首个生产平台操作及允许访问的真实资源范围；首批 Android 设备/系统配置；何时解除 iOS 实验暂缓；稳定兼容窗口和分发支持范围。没有决定真实资源前，前两项及第三项合成设计仍可独立推进。
