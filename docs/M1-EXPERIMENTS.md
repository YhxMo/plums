# M1 实验与工程决策

状态：当前有效（2026-10-17 核实）；M1 已限定收敛，长期决策与后续平台门槛见架构与整体计划。

M1 已按 Mac arm64 与 Android API36 ARM64 模拟器的限定范围收敛。当前开发与交付状态见[验证索引](../evidence/RESULTS.md)，工具链和构建入口见[开发流程](DEVELOPMENT.md)与[Android 工程](ANDROID.md)。

## 实验范围

| 实验 | 可观察结果 | 失败判据 |
| --- | --- | --- |
| 原生外壳 | Tauri/Web/Rust 桥接与隔离数据读写 | 原生调用不通，或把浏览器结果当作原生证据 |
| 扩展执行 | 随包本地 ESM 在 WebView 执行 | 依赖运行时 Node.js 或修改私有内核才能接入 |
| 生命周期 | 依赖就绪、替换、取消与释放 | 残留调用/资源，或清理失败伪报成功 |
| UI 替换 | 整体布局、导航和恢复入口可替换 | 仅能换色加按钮，或停用后无法恢复 |
| 状态 | 授权、保存、拒绝、取消与重启恢复 | 坏数据被覆盖、拒绝假成功或回执状态失真 |

## 决策记录

依赖以 npm/Cargo 锁文件固定；[直接依赖元数据](../evidence/dependency-licenses.json)和[收敛证据](../evidence/CONCLUSIONS-2026-10-15.md)保存原核对范围。

### 基于现有证据的选型结论

| 方案 | 采用理由与当前使用 | 重新评估条件 |
| --- | --- | --- |
| Tauri 2 / Rust | 原生能力集中在适配层；Mac 与指定 Android 模拟器已有桥接/状态/输入证据 | 新平台的桥接、WebView 或生命周期条件推翻现有契约 |
| React / TypeScript / Vite | 管理外壳与默认 UI 使用成熟工具；扩展以 DOM 挂载/释放，服务契约不依赖 React | 当前 UI 组合、可访问性或维护成本无法满足实际用例 |
| 本地可信 ESM | 依赖、资源和取消由 Host 作用域管理，运行时无需 Node.js | 运行不可信代码、不合作任务、强制配额或系统后台持续执行；共享 WebView/DOM/桥接不提供恶意代码隔离 |
| JSON 小快照 / 修订检查 | 每 owner 有独立文件，64 KiB 上限；业务格式留在扩展，已有单跳迁移和显式恢复助手 | 长会话/索引、容量、多进程、包升级事务或提交中崩溃恢复需要更强存储 |
| 精确 API / 服务版本 | 安装与消费时明确拒绝不兼容组合 | 稳定 SDK 的兼容窗口、废弃与迁移政策形成后统一调整 |

历史选型结论于 2026-10-15 按 `d44540b` 基线收敛；后续能力与剩余工作由[整体计划](spec/total.md#能力基线与剩余工作)维护。长期执行模型、分发支持和全量第三方许可证义务仍待确定。

## 最小 iOS 与 Android 实验

新增平台或配置先选择明确 OS/WebView、ABI 和隔离数据，再沿下列路径验收。Android 现有单配置结果绑定各自证据；iOS 尚未执行。工具下载、许可、设备配对和安全授权在对应操作前确认。

1. 核对锁定工具链、SDK/NDK、签名条件及生成工程；缺项记为该配置的阻塞。
2. 在没有 Vite/Node 开发服务的条件下安装并启动原生包，核对目录、ESM、CSS、MIME/CSP/Origin 和实际 Web API。
3. 经公开能力路径执行 grant/state.read/state.write，检查设备应用目录和回执，避免写到主机数据目录。
4. 替换服务和布局，停用提供者，检查消费者等待、资源/任务释放及恢复后的单份订阅。
5. 执行拒绝与故障路径，再以同一包冷启动，核对已确认保存的状态。
6. 在真实任务窗口中切换前后台并观察取消、回收和重建；正常重启与短任务结果分别记录。

Mac 与 Android 指定模拟器结果支持 M1 限定收敛；Android 真机及声明配置是稳定 Android 发布门槛，iOS 最小实验是接口正式稳定前门槛。Windows/Linux 按后续平台计划验收。长期后台、完整事务升级和崩溃恢复按实际用例推进。

## 依赖失效原生夹具

组合夹具同时提供服务与视图，建立两级消费者，并由健康通知服务在取消时同步发事件。失效时先关闭全受影响图的工作入口，再取消和串行释放；清理失败由所有者锁存。

复现时使用隔离副本，将 tests/fixtures/dependency-chain.js 和 dependency-state.js 复制到 extensions/fixtures，追加夹具导出的四个 catalog 项，仅修改 Tauri 产品名/标题/标识为 dev.plums.plums.chain-check，执行既有调试构建。普通包与该变体分别留证，见[配方与产物](../evidence/dependency-native.json)。其他原生边界夹具的入口见[状态、停用与焦点证据](../evidence/RELIABILITY-2026-10-15.md)。
