## 行为与反例

仅手动安装扩展可卸载；内置扩展只停用。流程为 stop → grant([]) → 保存不含该路径的 imports → Host.uninstall。第二次撤权保留 Host API 自身保证。所有步骤不删除扩展状态或模块文件；取消不更改注册；活动依赖先停止并等待服务恢复。

清理或首次撤权失败不保存路径移除；保存失败保留内存记录；第二次撤权失败可能已保存路径移除，但仍显示未完成并支持重试/重载，不声称原子事务。未知保存回执的写入锁存由既有实现保持，须重载确认实际保存结果。新增合成单元覆盖保存抛错后保留 live record、不继续卸载；未验证原生未知回执与重载全过程。

先建立缺失 shell 卸载模块的失败测试，再实现。独立审查发现成功后立即聚焦背景被 modal 阻止，新断言实际失败；改为关闭后的 effect 一次性聚焦管理标题，回归通过。取消回到尚存在的发起按钮。
