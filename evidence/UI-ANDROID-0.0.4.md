## 版本与验收

受验源码提交为 `de686c70fb5a8f08615b8377e8b847fcbf025d95`，基线为 `983c9dc9281f1aaed7e04355452c6b14338a2a24`。差异包含 Agent 扩展层服务、默认 UI、角色卡设置、外壳装配和串行保存、版本、测试，以及 Android 浅色背景的受控升级。通用 Host、ExtensionContext、平台桥接及 Rust 业务逻辑未改。构建对应此提交的源码；后续证据与交接编辑不改变运行代码。0.0.3 的 [77 文件集合](source-manifest.json)仅为历史版本，不作为本版源码标识。

验收失败条件包括：首次缺少添加或导入入口；角色说明被当作模型能力或授权；手机保留无意义标签栏；跨会话串消息；保存失败丢草稿；排队取消仍写入；会话变更与发送交叠；外部提供者需要私有状态或丢失方法接收对象；失效扩展路径阻断启动或重装后产生重复 ID；浮层内失败反馈不可见；停用残留资源或恢复丢失已存内容。

默认界面为浅灰/白色与橙色操作、暖炭灰深色两套主题。桌面采用 Agent 列表、会话和详情；手机列表与会话切页，详情为模态。空状态使用两张线性图标卡片，手机上下排列。特别关注提供多个头像快捷入口与星标。顶栏菜单提供扩展管理、角色卡设置、应用设置、诊断和关于；布局选择使用自定义按钮。

角色卡设置可选择现有角色、编辑名称和说明、导入 JSON 文件，并查看实际提供者与能力。内容由 `ui.agents` 的公开 `role-settings` 视图提供。当前内置提供者仅执行本地文本转换；完整角色卡标准、模型/MCP 客户端和 A2A 尚未实现。

## Mac 打包应用

环境为 macOS arm64、系统 WKWebView。运行 `release/Plums M1 0.0.4.app`，原生工具按完整应用路径绑定；隔离数据位于 `.m1-data/ui-0.0.4-final/`。

| 操作 | 观察结果 |
| --- | --- |
| 添加角色、启用多会话 | 列表出现角色，进入实际会话界面 |
| 输入后切换深色并发送 | 草稿保留；Rust `host.shell` 保存 `native_mac_final_004` 与 `NATIVE_MAC_FINAL_004` |
| 特别关注、新建/切换会话 | 星标快捷入口可用，两个会话独立，首个结果保留 |

最终 APK 实际验证添加、发送并经 Rust 保存、主题切换留草稿、特别关注、新建/切换会话、角色卡说明保存、停用零资源/任务与恢复、授权取消/确认、切回 Agent 布局和 force-stop 后的新进程恢复。设备 Rust 状态的首个会话含 `native_android_004` / `NATIVE_ANDROID_004`，第二个会话保持空白；说明为 `role_description_004`，关注为 true，布局/主题为 agents/dark。WebView localStorage 为空。

## 审查、精简与交付

独立审查覆盖公开提供者接入、串行保存与取消、会话结构修改、失效导入恢复、手机反馈及焦点。发现的问题均修复，并补充相应行为反例；定向复审无剩余阻塞。最后两处 CSS 的深浅悬停和输入焦点另行定向复核。独立审查未冒称重演全部原生操作。

精简范围为外壳装配/保存、默认 Agent UI 与受影响样式：特别关注只保存一个 `pinned` 字段；扩展启用与新视图选择共用入口；删除无用工具栏、页脚和失效选择样式，保留原工作台/画布诊断入口。通用宿主未增加聊天业务 API，也未引入额外主题或状态框架。

当前交付为 `release/Plums M1 0.0.4.app` 和 `release/plums-m1-0.0.4-android-arm64-debug.apk`，均为 debug。核验新包并更新清单后，0.0.3 的旧交付与说明可恢复归档，路径见 HANDOFF 和本地 release 说明；历史实验原件保留。

M1 保持开放。iOS 继续暂缓；Windows/Linux、完整 A11/A12、多 Agent 协作、跨提供者集合、完整组合/状态迁移、崩溃恢复、OS 文件授权与长期后台尚未完成。当前快照仍受 64 KiB 限制。
