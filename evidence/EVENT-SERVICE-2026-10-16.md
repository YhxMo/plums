## 已完成的行为

样板只使用公开 on/emit/task/platform/provide，没有注册或挂载业务视图，Host、SDK 和默认入口无需改动。测试页负责触发和展示结果，不承载业务生命周期。当前 [执行契约](../docs/EVENT-SERVICE.md)将暂停映射为 stop，重启新一代内存状态；撤权保持启动意图并等待重新授权。

浏览器真实预览适配、Mac arm64 专项包 WKWebView、Android 16 / API 36 ARM64 软件渲染隔离模拟器分别完成同一组 8 项检查：

| 路径 | 实际判据 |
| --- | --- |
| 未授权 | waiting，零视图，无回执；授权后才注册服务 |
| 无视图任务 | 事件启动跟踪任务，实际 state.read 后返回 done |
| 容量 | 一个等待任务在途，第二个事件收到 busy；这是样板策略，不是 Host 强制配额 |
| 停用 | 取消等待任务且不发成功，任务/资源归零，旧实例 received 不增加，旧能力引用拒绝 |
| 再启动 | 停用后只授权不启动；显式 start 创建新实例，事件只收到一份回执 |
| 撤权与恢复 | 撤权取消任务、等待授权，旧实例不接收事件；重新授权创建新实例且仅一个订阅，旧引用仍拒绝 |
| 卸载 | 停用后卸载，无旧监听，新事件不增加旧 received，旧能力引用继续拒绝 |
| 清理失败 | 合成 disposer 失败锁存 cleanup-failed，不能重启；监听不再工作，独立管理查询仍可用 |

取消发生在原生读取已经返回、任务进入 hold 后；没有验证原生 read 在途撤回。仅模拟单元注入能力不可用与读取失败：前者等待且零资源，后者 failed 可见、无成功回执、busy 释放并能处理下一请求。不得把这两项写成原生故障注入结果。
