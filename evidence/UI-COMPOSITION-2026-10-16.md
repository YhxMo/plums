## 契约与作者方法

可选 SDK `mountViewTree` 声明固定树、严格后代子根、路径循环/根占用冲突、取消、就绪和逆序清理。失败等待已启动子挂载并尝试全部清理；清理失败锁存占用，不能伪报释放或直接重启。Host 不理解任务板业务，生产 View.mount API 没有改变，见 [公开契约](../docs/VIEW-TREE.md)。

先冻结契约，再由两个隔离上下文的内部独立执行者只读公开契约和 SDK，分别编写计数面板服务和非聊天任务板容器；集成时调整相对导入。两者通过 `ui.panel@1` 公共服务组合，不读改 Host 私有逻辑。这是内部独立接入验证，不是社区反馈，也不是完整未知需求 A2。

测试外壳独立提供扩展管理入口。容器异步 ready 失败由适配器显示回退，不属于 Host 自动排除失败代际。清理失败归属承载树的视图扩展，尚无跨作者精确节点审计。默认应用不安装此组合，也没有增加生产管理页面。
