## 打包应用实测

平台：macOS 27.0.1 arm64。直接启动包内可执行文件，`HOME` 指向 `.cache/acceptance/memory-2026-10-25/home`，数据从空开始。所有者自行添加 DeepSeek 连接并填写密钥，选择 `deepseek-flash`，没有设置最大输出（与发布后的默认用法相同）。经所有者授权，共调用 DeepSeek 4 次：回复 3 次、整理 1 次。结果从隔离目录中两个扩展的 SQLite 存储副本读取。

| 项 | 结果 |
| --- | --- |
| 关于我 | 从头像打开的“关于我”写入“我叫”加一个名字（`person` 作用域）。新 Agent 的第一条回复用这个名字打招呼，说明共享记忆进入了系统提示词 |
| 设定 | 新 Agent 的设定是预填的“简洁、友好地回答用户的问题。”，介绍为空 |
| 发言者 | 4 条消息都带 `from` |
| 真实整理 | 20:21:43 说“我后天下午三点要去看牙医”；20:22:12 离开会话后，整理写入“2026年10月27日下午三点要看牙医”（`agent` 作用域，来自对话），`at` 为当地时间 2026-10-27 15:00，相对时间按消息时间换算正确。整理进度记到最后一条消息（20:21:46），这批消息不会再发送 |
| 重启后跨会话 | 退出后用同一数据重启，在新会话问“我后天有什么安排”，回复“你后天（10月27日，周二）下午三点要看牙医。” |
